# Noisy Studios: Portfolio

> Portafolio de desarrollo de videojuegos realizado por un equipo de tres estudiantes.

Noisy es un estudio de videojuegos creado como parte de un proyecto académico. Este portafolio reúne nuestro proceso de trabajo, proyectos y aprendizajes a lo largo del desarrollo, mostrando nuestras habilidades en áreas como programación, diseño, arte y desarrollo de videojuegos.

### Wireframes:

#### Desktop:

Nuestros wireframes para la versión de escritorio fueron diseñados teniendo como referencia una MacBook Pro de 16 pulgadas, considerando sus dimensiones y proporciones de pantalla para establecer una distribución adecuada de los elementos y garantizar una experiencia visual organizada y consistente.

#### Tablet:

Para la versión de tablet, los wireframes fueron desarrollados tomando como referencia un iPad Pro de 12.9 pulgadas. El diseño fue adaptado a las características y dimensiones de este dispositivo, buscando mantener una navegación clara y una correcta organización de los contenidos en una pantalla táctil.
